# reference/ — private benchmark screenshots (optional)

Drop screenshots of benchmark titles here (PNG/JPG, >= 1280 px wide) to enable the **blind A/B test**
(`node tools/ab.mjs`, see docs/QUALITY_BAR.md). Suggested: 6-10 stills each of flagship cozy-adventure titles - landscapes, character close-ups, interiors, night, water.

- These files are git-ignored (see .gitignore) and are used only for private, internal quality comparison.
- Never copy their art, characters, names or audio into the game. We match their *polish tier*, not their IP.
- If this folder is empty, critics fall back to rubric-only scoring and log "no refs" in docs/ab_results.json.
